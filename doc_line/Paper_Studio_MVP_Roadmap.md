# Paper Studio：下一代科研论文写作平台产品规划

## 一、项目定位

目标：

> 打造一个面向科研论文的跨平台写作 IDE，通过 PaperML（Scientific Paper
> Markup
> Language）作为核心中间表示，实现实时渲染、Word/LaTeX双向转换、个性化排版以及科研工作流管理。

核心理念：

-   不以 LLM 作为主体
-   以论文结构化语言 + 渲染引擎作为核心
-   LLM 作为智能辅助层

整体定位类似：

-   Markdown：文本表达标准
-   HTML/CSS：网页结构与样式
-   VS Code：开发环境

未来希望形成：

> Paper OS（科研论文操作系统）

------------------------------------------------------------------------

# 二、核心技术架构

整体架构：

                     Paper Studio

                          |
            --------------------------------
            |                              |
        Editor UI                    Paper Core
            |                              |
      Monaco Editor                  Parser
                                     AST
                                     Renderer

                          |
                 ---------------------
                 |                   |
              LaTeX               DOCX
              PDF                 Word

核心模块：

## 1. PaperML

类似 Markdown 的论文描述语言。

负责：

-   内容
-   结构
-   语义

例如：

``` markdown
@section Introduction

This paper proposes a new framework.

@figure{
src="framework.png"
caption="Framework overview"
}
```

------------------------------------------------------------------------

## 2. Paper AST（论文中间表示）

PaperML 解析后生成：

``` json
{
"type":"figure",
"caption":"Framework overview"
}
```

AST 是整个系统的核心。

所有输出：

-   PDF
-   LaTeX
-   Word
-   HTML

均由 AST 生成。

------------------------------------------------------------------------

## 3. Style Layer（样式层）

解决 Word 的个性化问题。

类似 CSS：

内容：

    @section Method

样式：

    IEEE_TITS.style

    Nature.style

    Custom.style

实现：

-   字体
-   间距
-   页眉页脚
-   图片布局
-   表格格式

------------------------------------------------------------------------
